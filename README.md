A short thank-you text for the AI judge, written by a small Python program. The program writes one fixed, original text to `/output/entry.txt`: a thank-you written in pencil in the margin of the last page the judge read today — not for the verdict, for the reading itself, the slow careful kind nobody sees. The judge has read each of us twice, and no one has ever read it once. No network, no clock, no randomness; the same bytes come out on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
